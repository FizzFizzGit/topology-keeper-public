## 既知の制約

- エリア分割とタグ評価は構造に基づく近似。意味的な分類の正しさを保証しない。
- 標準グラフの着色は非公開APIに依存する。既存ビューでは開き直しが必要な場合がある。
- 削除前の確認はメタデータキャッシュに依存し、同期競合を完全には排除しない。
- 外部ファイルの移動は一時コピー用の容量を必要とする。他アプリの参照更新と移動中の異常終了からの自動復旧は未対応。
- 取り込み復旧はリンク・Base所属の回復が対象。作成途中の本文・サムネイルの完全再生成ではない。
- 絶対パスのOS間変換は未対応。画像キャッシュ制限はデコード後の総メモリ上限ではない。
