# 開閉操作の共通ルール

メイン小窓・分析結果・孤立・部分グラフで、個別の例外サイズではなく用途と階層で揃える。

| 種類 | 表現 | サイズ |
| --- | --- | --- |
| 大見出しの開閉 | 共通ベクターの右向き／下向き山形 | 20px、見出しの最小高さ32px |
| 内側の折り畳み | 同じベクターの縮小版 | 14px、見出しの最小高さ28px |
| 別ウィンドウ・グラフを開く／閉じる | 操作に応じたSVGアイコン | 16px、独立ボタンの枠28px |

大見出しはファイル管理、エリア候補、孤立ノート、管理データの整理。内側は個別エリア、タグのみの接続、チェック対象外の一覧、ファイル管理内の小分類。

インジケータとタグ名ボタンは内容に合わせて伸縮する複合ボタンだが、操作を示すアイコンは同じ16pxを使う。タグ名ボタンの最小高さは28px。インジケータの開く／閉じるヒントも16px。

サイズは `src/styles.css` の共通変数 `--tk-disclosure-major`、`--tk-disclosure-minor`、`--tk-action-icon`、`--tk-action-hit` で定義する。共通規則はファイル末尾にまとめている。ボタンはフラットな通常表示とホバー・キーボードフォーカスの反応を持つ。

開閉マークはフォントの三角文字を使わず、同一のSVGマスクを90度回転させる。太字・フォント・言語による字形差を避け、ブラウザ標準のマーカーも隠す。全種類で中央揃えと6pxの間隔を共有する。

ヘッダーの共通操作はネイティブのbuttonを使用する。部分グラフの閉じる操作も他のウィンドウと同じ×アイコンにし、操作名をツールチップとaria-labelに残す。折り畳みはdetails/summaryを使用し、summaryの内側には別操作のボタンを入れない。
